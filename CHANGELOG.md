# Changelog

All notable changes to DoomDeck are documented here.

DoomDeck uses Semantic Versioning and Conventional Commits. Release entries are generated by Python Semantic Release.

<!-- version list -->

## v1.0.0 (2026-06-09)

### Highlights

- Added automated GitHub releases and supported-Python CI coverage.
- Added safe archive extraction, bounded downloads, and validated GitHub payloads.
- Added ModDB WAD installation and managed mod provenance.
- Extracted domain, application, validation, download, and mod-install boundaries.

## v0.2.0 - 2026-05-31

### Chores

### Continuous Integration

- Add GitHub release workflow.

### Features

- Install ModDB WAD archives.

Initial packaged baseline for the DoomDeck CLI.
